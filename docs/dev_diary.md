# Дневник разработки AvaVibeTweak

## Активные задачи и лог

### 14 июля 2026
**Что сделано:**
- Инициализирован проект AvaVibeTweak (библиотека и тестовое приложение TestApp).
- Разработана архитектура интеграции (Zero-config) через `AppBuilderExtensions.UseAvaVibeTweak()`.
- Реализован глобальный перехватчик событий (`VibeOverlayManager`) для активации режима дизайна по `F11`.
- Реализована отрисовка обводки (HighlightAdorner) и плавающего окна индикатора (IndicatorPopup).
- Разработана панель редактирования свойств (`PropertiesPanelPopup`) с поддержкой C# Reflection для безопасного редактирования (Padding, Margin, FontSize, Width, Height) без падений.
- Настроен темный дизайн в стиле Premium UI.

**Архитектурные решения:**
- Использование `Popup` вместо `AdornerLayer` для панели свойств и окна-индикатора для обхода жестких ограничений обрезки (`Clip`) в Avalonia 11.
- Применение Reflection (`GetProperty`) для безопасной работы с UI-элементами, чтобы избежать `ArgumentException` на свойствах, которые не наследуются напрямую (например, `Padding` у `TextBlock`).
- Использование `Task` и `CancellationToken` (будет применено) для будущих асинхронных операций экспорта патчей.

**Проблемы и их решение:**
- *Проблема:* Панель свойств не появлялась и сжималась. *Решение:* Переход с Adorner на Popup.
- *Проблема:* Краш при клике на текст из-за отсутствия свойства `Padding`. *Решение:* Проверка наличия свойства через `Reflection` перед биндингом.

**Планы на следующий шаг:**
- Рефакторинг стилей `PropertiesPanelPopup` под строгие правила `premium-ui` (цвета slate-900, тени, скругления 16px).
- Рефакторинг структуры проекта (перенос в папку `src/`) в соответствии с `project-structure-and-docs`.
