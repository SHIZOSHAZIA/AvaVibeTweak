# AvaVibeTweak 🎨

**AvaVibeTweak** — это мощный визуальный редактор (overlay) для разработчиков на Avalonia UI. 
Он позволяет настраивать цвета, размеры, отступы и другие визуальные свойства вашего приложения прямо во время его работы (в режиме реального времени)!

Никакого больше редактирования XAML вслепую. Кликайте на элементы, двигайте ползунки и сохраняйте идеальный дизайн. А ваш ИИ-ассистент перенесет эти черновики прямо в ваш код!

## ✨ Особенности
- **Интерактивный UI:** Редактируйте любые свойства прямо поверх вашего работающего приложения (F12).
- **Генерация визуальных путей (Visual Tree Paths):** Утилита сама найдет точный путь до элемента (даже если у него нет `x:Name` или он внутри шаблона DataTemplate).
- **ИИ-Интеграция:** Сохраняйте черновики в файл `vibe_patch.json` и поручите ИИ встроить их в ваш `*.axaml` код!
- **Zero-Overhead в релизе:** Утилита работает только в режиме `DEBUG`. В финальную версию вашего приложения не попадет ни одного лишнего байта.

## 🚀 Установка (Для разработчиков)

Чтобы интегрировать AvaVibeTweak в ваш проект так, чтобы он не утяжелил вашу финальную программу (Release), следуйте этой инструкции:

### Способ 1: Продвинутый (Git Submodule)
Рекомендуется, если вы пользуетесь Git. Это позволит легко обновлять утилиту одной командой.
1. Откройте терминал в папке вашего проекта и введите:
   ```bash
   git submodule add https://github.com/SHIZOSHAZIA/AvaVibeTweak.git Tools/AvaVibeTweak
   ```
2. Откройте ваш основной файл `.csproj` и добавьте ссылку на утилиту. **Обязательно добавьте условие `Condition`**, чтобы утилита не попала в релиз:
   ```xml
   <ItemGroup>
     <!-- Загружать только при отладке (Debug) -->
     <ProjectReference Include="Tools/AvaVibeTweak/src/AvaVibeTweak/AvaVibeTweak.csproj" Condition="'$(Configuration)' == 'Debug'" />
   </ItemGroup>
   ```

### Способ 2: Простой (Zip-архив)
Если вы не хотите использовать Git подмодули:
1. Скачайте этот репозиторий как ZIP-архив (кнопка `Code -> Download ZIP`).
2. Извлеките папку `src/AvaVibeTweak` в ваш проект (например, по пути `Tools/AvaVibeTweak`).
3. Добавьте `<ProjectReference ... Condition="'$(Configuration)' == 'Debug'" />` на этот скачанный файл проекта.

## 🛠️ Как использовать в коде

1. Перейдите в файл `Program.cs` (или `App.axaml.cs`), где вы инициализируете приложение Avalonia.
2. Подключите пространство имен: `using AvaVibeTweak;`
3. Добавьте вызов `.UseAvaVibeTweak()` к вашему `AppBuilder`, обязательно обернув его в директиву препроцессора `#if DEBUG`:

```csharp
using Avalonia;
using AvaVibeTweak; // 1. Подключаем

class Program
{
    public static void Main(string[] args) => BuildAvaloniaApp().StartWithClassicDesktopLifetime(args);

    public static AppBuilder BuildAvaloniaApp()
    {
        var builder = AppBuilder.Configure<App>()
            .UsePlatformDetect()
            .WithInterFont()
            .LogToTrace();

#if DEBUG
        // 2. Активируем визуальный редактор только при отладке!
        builder.UseAvaVibeTweak();
#endif

        return builder;
    }
}
```

Запустите ваше приложение. Нажмите **F12** (или вызовите редактор другим способом), чтобы открыть оверлей! Выделите элемент, измените значения и нажмите `Ctrl + S`, чтобы сохранить патч.

## 🤖 Как переносить изменения в код (Antigravity AI)

AvaVibeTweak задуман как "глаза" для ИИ. Когда вы нажимаете сохранить, создается файл `vibe_patch.json`.

Если вы используете IDE **Google Antigravity** или другого совместимого агента:
1. Скопируйте папку `.agents` из этого репозитория в корень вашего проекта.
2. В чате с агентом просто напишите:
   > **«примени патч UI»**
3. ИИ-ассистент прочитает пути из JSON, сам найдет нужные XAML-файлы, бережно обойдет ваши `Bindings` (привязки данных) и внедрит стили прямо в ваш код!

*(Никаких костылей в виде рантайм-применения стилей — ваш исходный код остается чистым и правильно сформатированным).*
